How to make an "exe" out of the Ares .bat file so you can add the mod to steam as non-steam game.
There could probably be other ways to do this but this looks cooler to have :p

This method uses a windows native program "iexpress" and a bat script file "Rem Original Script https://github.com/npocmaka/batch.scripts/blob/master/hybrids/iexpress/bat2exeIEXP.bat".

The bat script does NOT use the internet or contact any external hosts.

All you have to do is to drag and drop the RedAlert2Ares.bat file to bat2exeIEXP.bat

Follow these steps first:

1a) Right click and edit the RedAlert2Ares.bat

1b) Change the directory to your own game directory, for example C:\Games\Steam\steamapps\common\Command & Conquer Red Alert II
	NOTE: Currently the exe is set to my own directory G:\Games\Steam\SteamLibrary\steamapps\common\Command & Conquer Red Alert II, sorry about that, but am too bored to fix it.

1c) Drag and drop RedAlert2Ares.bat at bat2exeIEXP.bat and the exe will be created.
	NOTE: You can rename the RedAlert2Ares.bat file to whatever you want.

2) Use a hex editor to edit the icon of the exe. I used Resource Hacker from https://www.angusj.com/ (click that link at your own risk).

3) On steam, click on "add a game" (Bottom left corner of the steam window, while you are at your game "LIBRARY" tab) and then click on "Add a non-steam game" and select the exe file you made.

4) Use the art covers i've inlcuded in the folder named "Add a Game Steam Covers".
